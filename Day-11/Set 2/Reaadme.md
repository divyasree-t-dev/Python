# Utility Billing Calculator

## Overview
A Python-based Utility Billing Calculator that calculates monthly electricity bills based on consumption slabs, consumer categories, fixed charges, and applicable surcharges or rebates.

## Features
- Calculates electricity charges using four consumption slabs.
- Applies category-based fixed charges using `match-case`.
- Calculates surcharge and rebate amounts.
- Processes monthly readings for 12 months.
- Uses a `while` loop to accept readings until the user quits.
- Validates meter readings and handles invalid inputs.
- Displays formatted billing details.

## Technologies Used
- Python 3.13
- Match-Case
- For and While Loops
- Conditional Statements
- Type Conversion
- F-Strings

## How to Run

```bash
python driver.py
```

## Learning Outcomes
- Implementing slab-based billing calculations.
- Working with loops and conditional statements.
- Handling invalid user inputs.
- Applying business rules using Python.
