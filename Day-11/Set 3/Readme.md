# Insurance Premium Bands

## Overview
A Python-based Insurance Premium Calculator that calculates insurance premiums based on customer details, BMI categories, and applicable premium loading factors.

## Features
- Calculates BMI using height and weight.
- Classifies BMI into different categories.
- Applies premium loading based on predefined conditions.
- Uses `match-case` with guards for decision-making.
- Calculates final insurance premiums using arithmetic operators.
- Validates customer details in batch processing.
- Handles invalid inputs and type conversion errors.

## Technologies Used
- Python 3.13
- Match-Case with Guards
- Conditional Statements
- Loops
- Type Conversion
- Exception Handling
- F-Strings

## How to Run

```bash
python driver.py
```

## Learning Outcomes
- Implementing BMI-based classification.
- Understanding match-case guards.
- Applying arithmetic operators and operator precedence.
- Validating multiple customer records.
- Handling runtime input errors.
